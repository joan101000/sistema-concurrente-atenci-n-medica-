# Sistema Concurrente de Atención Médica

Proyecto desarrollado en Python para la asignatura Sistemas Operativos.

El sistema simula la atención de pacientes mediante procesos concurrentes y paralelos, utilizando el patrón Productor-Consumidor.

## Funcionalidades

- Ejecución secuencial.
- Ejecución paralela con múltiples procesos.
- Prioridades de atención: alta, media y normal.
- Comunicación mediante Queue y JoinableQueue.
- Sincronización mediante Value y Lock.
- Validación de resultados.
- Cálculo de speedup, eficiencia y mejora.
- Análisis de escalabilidad con diferentes cantidades de procesos.
- Interfaz gráfica desarrollada con CustomTkinter.

## Archivos principales

- `procesamiento.py`
